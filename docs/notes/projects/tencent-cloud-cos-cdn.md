# 腾讯云 COS 私有桶 + CDN 加速完整配置流程

> 目标：私有读写存储桶（防盗链/防盗刷）+ 自定义源站域名（直连，需签名）+ 自定义 CDN 加速域名（公开分发，免签名）。
> 适用：图床、静态资源分发、站点动静分离。
> 示例信息（可全局替换为自己的）：桶 `examplebucket-1250000000`，地域 `ap-shanghai`，主域名 `example.com`。

---

## 一、整体架构与三条访问链路

```
                        ┌────────────────────────────────┐
   ① 直连源站（需签名）  │  examplebucket-1250000000      │
   img.example.com ────▶│  .cos.ap-shanghai.myqcloud.com │  私有读写桶
   自定义源站域名        │  （COS 源站）                   │
                        └───────────────┬────────────────┘
                                        │ 回源（CDN 服务身份授权）
                        ┌───────────────▼────────────────┐
   ② CDN 加速（免签名）  │  img-cdn.example.com           │
   用户浏览器 ─────────▶│  .cdn.dnsv1.com                │  CDN 边缘节点
   自定义 CDN 加速域名   │  （已缓存 → 直接返回）           │
                        └────────────────────────────────┘

   ③ 默认域名（不建议使用）：<Bucket>-<APPID>.cos.<Region>.myqcloud.com
```

| 链路 | 域名 | 是否需签名 | 是否走 CDN | 典型用途 |
|---|---|---|---|---|
| ① 自定义源站域名 | `img.example.com` | **需要**（预签名 URL） | 否，直连源站 | 后台上传、管理、临时授权下载 |
| ② 自定义 CDN 加速域名 | `img-cdn.example.com` | **不需要** | 是 | 前端页面引用、公开分发 |
| ③ COS 默认域名 | `<bucket>.cos.<region>.myqcloud.com` | 需要 | 否 | 仅调试，别暴露到业务里 |

**核心原则：CDN 域名免签名是刻意为之** —— 签名参数（如 `q-sign-time`、`q-signature`）每次都不同，带签名的 URL 无法命中 CDN 缓存，等于加速白配。所以签名校验由"CDN 回源鉴权"这一段承担，用户侧 URL 保持干净。

## 二、前置条件（先满足，否则后面全是坑）

| 项 | 要求 | 说明 |
|---|---|---|
| 域名备案 | **必须** | 加速地域选"中国境内"要求域名已完成 ICP 备案（不强制在腾讯云备案，备过即可）；境外/全球可不备案 |
| 实名认证 | 必须 | 腾讯云账号完成实名认证，否则申请不了 SSL 证书 |
| 开通服务 | COS、CDN | CDN 需开通（默认按量后付费，有免费额度） |
| 域名解析商 | DNSPod 或其他 | 推荐托管到腾讯云 DNSPod，SSL 证书支持"自动 DNS 验证"，省很多事 |
| 密钥准备 | 子账号密钥 | **强烈建议**用 CAM 子账号密钥，只授予该桶的最小权限，不要拿主账号 SecretId/SecretKey 做业务签名 |

> ⚠️ 备案同步有 1~2 小时延迟，刚备完案立刻添加加速域名可能被拦截。

## 三、第一阶段：创建存储桶（私有读写）

**控制台**：对象存储 COS → 存储桶列表 → 创建存储桶

| 配置项 | 建议值 | 备注 |
|---|---|---|
| 名称 | 如 `examplebucket-1250000000` | 含 APPID，创建后不可改 |
| 地域 | 与业务/用户就近，如 `ap-shanghai` | **创建后不可更改** |
| 访问权限 | **私有读写** | 防盗链第一道防线：匿名访问一律拒绝 |
| 服务端加密 | 按需 | 一般可不开启 |
| 多 AZ | 按需 | 生产建议开启 |

**私有读写的含义**：任何匿名请求（无论走哪个域名）都会被 COS 拒绝返回 403。后续所有访问都必须经过"签名"或"CDN 回源授权"两条路之一。

## 四、第二阶段：自定义源站域名（直连链路，需签名）

路径：`存储桶 → 域名与传输管理 → 自定义源站域名 → 添加域名`

### 配置三步走

**① 添加域名**
- 域名填：`img.example.com`（不要与后面 CDN 域名重复）
- 源站类型：**默认源站**（私有读写桶，不开静态网站）
- 保存后控制台会给出 CNAME 目标：`<Bucket>-<APPID>.cos.<Region>.myqcloud.com`

**② DNS 解析**
去 DNSPod 添加记录：

| 主机记录 | 记录类型 | 记录值 |
|---|---|---|
| `img` | CNAME | `examplebucket-1250000000.cos.ap-shanghai.myqcloud.com` |

**③ 绑定 SSL 证书**
在自定义源站域名列表 → 该域名 → **绑定证书**：
- 腾讯云托管证书（已在 SSL 控制台申请过的，直接选）
- 或手动上传证书 + 私钥
- 建议同时开启 **强制 HTTPS**

> ⚠️ 证书是绑定域名的。这张证书只覆盖 `img.example.com`，**不能**给 `img-cdn.example.com` 用 —— 除非你买的是 `*.example.com` 通配符证书（免费证书不支持通配符，只能买单域名证书或付费泛域名证书）。

### 直连访问：必须加签

用源站域名（默认域名或自定义源站域名）访问私有桶，**每个请求都必须带签名**。

三种签名方式：

| 方式 | 适用场景 | 说明 |
|---|---|---|
| **预签名 URL** | 临时分享、前端直传/下载 | 后端用 SecretId/SecretKey 按算法生成有时效的 URL，参数形如 `?q-sign-algorithm=...&q-ak=...&q-sign-time=...&q-key-time=...&q-header-list=...&q-url-param-list=...&q-signature=...` |
| **Header 签名** | 服务端 SDK 调用 | 各语言 SDK 自动完成，业务代码无感 |
| **临时密钥 STS** | 前端/移动端 | 后端通过 STS 下发临时密钥，避免把永久密钥写进客户端，**推荐用于前端直传** |

**关键坑**：如果后端生成了预签名 URL，但业务上要走 CDN，正确姿势是 ——
```
用【源站域名】计算签名 → 再把域名替换成【CDN 域名】
```
反过来（直接拿 CDN 域名去算签名）会签名校验失败，因为签名的 Host 参与计算。

## 五、第三阶段：自定义 CDN 加速域名（公开分发，免签名）

路径：`存储桶 → 域名与传输管理 → 自定义 CDN 加速域名 → 添加域名`

### 必须新开一个子域名

**CDN 域名不能复用源站域名**。原因是两条链路的 CNAME 目标不同（一个指向 COS 源站，一个指向 CDN 的 `*.cdn.dnsv1.com`），同一个主机记录只能有一条 CNAME，复用必然冲突。

建议：`img-cdn.example.com`、`static.example.com`、`cdn.example.com` 等。

### 域名归属验证（首次接入必过）

弹窗会提示"请先验证域名的归属权"，给出 TXT 记录：

| 主机记录 | 记录类型 | 记录值 |
|---|---|---|
| `_cdnauth` | TXT | 控制台随机生成的一串字符 |

**要点（踩坑重灾区）**：
1. **TXT 加在主域名下**，即 `_cdnauth.example.com`。无论加速域名是几级（`c.b.a.example.com` 也一样），主机记录都只填 `_cdnauth`，**不要**填 `_cdnauth.img-cdn`。
2. 记录值用**复制按钮**，别手打；每次重开弹窗值可能变化，旧值残留会导致 `CdnTxtRecordValueNotMatch`。
3. 必须加在**权威 DNS 服务商**（看 Nameserver 指向哪），加错平台永远读不到。
4. 保存后**等 5~10 分钟**再点验证。可先用命令自检：
   ```bash
   nslookup -type=txt _cdnauth.example.com     # Windows
   dig TXT _cdnauth.example.com                # Mac / Linux
   ```
5. DNS 实在搞不定 → 切**文件验证**：下载 `verification.html` 上传到 `example.com` 根目录，确保 `http://example.com/verification.html` 可访问。

### 弹窗配置项

| 配置项 | 私有读写桶的取值 | 说明 |
|---|---|---|
| 域名 | `img-cdn.example.com` | 已备案的新子域名 |
| 加速地域 | 中国境内 / 中国境外 / 全球加速 | 按用户分布选 |
| 源站类型 | **默认源站** | 桶开了静态网站才选"静态网站源站"；开了全球加速才选"全球加速源站" |
| **回源鉴权** | **必须开启** | 私有读写桶不开 = CDN 回源全 403，一个资源都拉不到 |

### 回源鉴权的前置：CDN 服务授权

**顺序不能反**：
1. 先点 **「添加 CDN 服务授权」**（桶的「权限管理」或弹窗内一键授权），勾选同意
2. 会自动往桶的 Bucket Policy 写入授权，授予 CDN 服务身份执行 `GET Object` / `HEAD Object` / `OPTIONS Object`
3. **再**打开回源鉴权开关

> ⚠️ 授权按主账号生成服务账号，**跨账号绑定加速域名会被拒绝**。

> 🔴 **必须知道的安全副作用**：开启授权 + 回源鉴权后，CDN 回源**无需携带签名**，且缓存内容会公网分发 —— 任何人拿到 `img-cdn.example.com/xxx.jpg` 都能直接访问。桶本身仍是私有的（直连源站仍需 COS 签名），但 **CDN 这个入口等于对全网开放**。所以下一步的安全加固不是可选项。

### DNS 解析 + SSL 部署

**DNS（DNSPod）**：

| 主机记录 | 记录类型 | 记录值 |
|---|---|---|
| `img-cdn` | CNAME | `img-cdn.example.com.cdn.dnsv1.com` |

**SSL 证书**：

1. 去 **SSL 证书控制台 → 我的证书 → 申请免费证书**
   - 绑定域名：`img-cdn.example.com`
   - 验证方式：自动 DNS 验证（域名在 DNSPod 时）
   - **私钥密码留空**（填了无法部署到 CDN）
   - 免费证书：TrustAsia DV、**有效期 90 天**、仅单域名、不支持通配符、每账号 50 张
2. 签发后 → 证书详情 → **一键部署 → 选 CDN** → 选 `img-cdn.example.com`
   （或 CDN 控制台 → 域名管理 → 管理 → HTTPS 配置 → 配置证书 → 腾讯云托管证书）
3. 勾选 **HTTP 强制跳转 HTTPS**
4. 设置 **回源协议**：COS 源默认支持 HTTPS，建议 `HTTPS 回源` 或 `协议跟随`；若回源异常可改回 HTTP

> HTTPS 是 CDN 增值服务，按请求数计费，**每账号每月 300 万次免费额度**，超出约 0.05 元/万次（以官方实时计费为准）。

### 私有读桶的四种组合（官方文档口径）

| 回源鉴权 | CDN 鉴权（URL 时间戳鉴权） | 通过 CDN 访问 | 通过 COS 源站访问 | 评价 |
|---|---|---|---|---|
| 开 | 开 | 需 URL 鉴权 | 需 COS 鉴权 | ✅ **全链路保护，最安全** |
| 开 | 关 | 直接可访问 | 需 COS 鉴权 | ⚠️ 源站保护，但 CDN 可被盗刷 |
| 关 | 任意 | **不可访问** | 需 COS 鉴权 | ❌ CDN 用不了 |

## 六、第四阶段：安全加固（强烈建议，别跳过）

全部在 **CDN 控制台 → 域名管理 → 点域名「管理」** 里配置。

### 访问控制（Tab：访问控制，全部免费）

| 配置 | 建议 | 说明 |
|---|---|---|
| **防盗链配置** | 白名单填 `example.com`，勾 **拒绝空 Referer** | 挡住站外盗图和 curl 直接请求 |
| **IP 访问限频** | 开启，限制单 IP 单节点每秒请求数 | 抗 CC / 脚本刷量 |
| **IP 黑白名单** | 按需 | 拦恶意 IP |
| **UA 黑白名单** | 按需，可挡 `curl/`、`Wget/`、`ApacheBench/` | 拦脚本 |
| **鉴权配置** | **URL 时间戳鉴权**（TypeA/B/C/D） | 最强防护，URL 带 `?sign=xxx&t=xxx`，过期失效。代价：需后端参与签名计算 |
| **下行限速** | 谨慎 | 全站生效，会影响正常用户体验 |

> 图床场景推荐组合：**Referer 白名单 + IP 访问限频 + 用量封顶**。URL 鉴权防护最强但需要后端改造，静态图床接入成本高。

### 用量封顶（Tab：高级配置）

路径：`CDN 控制台 → 域名管理 → 管理 → 高级配置 → 用量封顶配置`
直达：`https://console.cloud.tencent.com/cdn/domain`

| 配置项 | 建议值 |
|---|---|
| 统计类型 | 累计用量 |
| 统计周期 | 自然天（或自然月，按日常量级） |
| 封顶配置 | 流量封顶（阈值 = 日常峰值 × 3~5 倍，先去「统计分析」看真实数据） |
| 超出阈值 | **访问返回 404** |
| 告警阈值 | 80% |

> 🔴 **COS 源专项限制**：源站类型为 COS 源的域名，超出阈值**只支持"访问返回 404（关闭 CDN 服务）"**，不支持"访问回源"。触发后图床全站 404，需回域名管理页**手动重新上线**，且要先调高阈值否则下一轮扫描会再次停用。
>
> ⚠️ 生效有 **约 10 分钟延迟**，期间消耗照常计费。它只是兜底止损，不是实时熔断。

### 监控与告警

- 腾讯云可观测平台：对域名流量/带宽设告警（比 CDN 5 分钟扫描粒度更快）
- SSL 证书到期提醒（免费证书 90 天，务必设，漏了会全站证书报错）
- CDN 用量封顶告警消息（站内信/短信/邮件）

## 七、第五阶段：性能与体验优化

| 配置 | 位置 | 说明 |
|---|---|---|
| **缓存配置** | 缓存配置 Tab | 图片类建议缓存 30 天以上；开启"忽略 URL 参数"可提升命中率（注意别把签名参数也算进去，虽然 CDN 侧本就不带签名） |
| **CDN 智能压缩** | 个性化配置 | 默认已开 gzip，可再考虑 Brotli |
| **图片自适应压缩** | 个性化配置 | 自动转 WebP/AVIF，图床收益明显，按量计费注意成本 |

| **CORS 跨域** | COS 桶「安全管理 → 跨域访问 CORS」 | 前端 canvas / fetch 跨域读图必须配 |
| **回源超时/重试** | 回源配置 | 一般默认即可 |
| **图片处理** | 数据万象 CI | 缩略图、水印、格式转换，可与 CDN 联动 |

## 八、验证清单（配完逐条过）

```bash
# 1. DNS 是否生效
nslookup img.example.com            # 应 CNAME 到 *.cos.ap-shanghai.myqcloud.com
nslookup img-cdn.example.com        # 应 CNAME 到 *.cdn.dnsv1.com

# 2. 源站直连（不带签名 → 应 403，证明桶是私有的）
curl -I https://img.example.com/test.jpg

# 3. 源站直连（带预签名 → 应 200）
curl -I "https://img.example.com/test.jpg?q-sign-algorithm=..."

# 4. CDN 访问（不带签名 → 应 200，证明回源鉴权生效）
curl -I https://img-cdn.example.com/test.jpg

# 5. 看是否命中 CDN 缓存（看 X-Cache 响应头）
curl -I https://img-cdn.example.com/test.jpg | grep -i x-cache
#   以 HIT 开头 = 命中缓存；MISS = 回源（首次访问正常，多刷几次应转 HIT）

# 6. HTTPS 证书是否正确
curl -vI https://img-cdn.example.com/test.jpg 2>&1 | grep -i "subject:"
```

浏览器侧：开发者工具 → Network → 看响应头 `X-Cache` 和 `X-Cache-Lookup`。

## 九、常见坑速查

| 现象 | 原因 | 解法 |
|---|---|---|
| 添加 CDN 域名报"任务已完成（已失败 1 个）" | 复用了已占用的源站域名 | 换新子域名 |
| `CdnTxtRecordValueNotMatch` | TXT 层级错 / 值已刷新 / 加错 DNS 平台 | 加 `_cdnauth.example.com`（主域名下）；重开弹窗重复制值；确认权威 DNS |
| 走 CDN 全 403 | 私有桶没开回源鉴权或没做 CDN 服务授权 | 先授权 → 再开回源鉴权 |
| 走 CDN 报签名错误 | 拿 CDN 域名去算了签名 | 用源站域名算签名，再替换域名为 CDN 域名 |
| 网站图片全挂 | HTTPS 页面引用 HTTP 图片（混合内容被拦截） | 给 CDN 域名配证书 + 开强制 HTTPS |
| 证书无效警告 | 拿了源站域名的证书给 CDN 域名用 | 单独申请 `img-cdn.example.com` 证书，或买 `*.example.com` 通配符证书 |
| 用 CDN 域名上传 | CDN 加速域名只加速下载，上传无加速效果 | 上传走源站域名 + 签名 |
| 图床突然全 404 | 触发了用量封顶 | 域名管理页重新上线，**先调高阈值**再上线 |
| 缓存一直不命中 | URL 带了签名参数 / 缓存规则太短 | CDN 侧 URL 保持干净；延长缓存时间 |
| 前端跨域读图失败 | 桶没配 CORS | COS 桶「安全管理 → 跨域访问 CORS」配置 |

## 十、一页纸配置清单

```
□ 域名 example.com 已完成 ICP 备案（等 1~2 小时同步）
□ 创建存储桶 examplebucket-1250000000（ap-shanghai，私有读写）
□ 自定义源站域名 img.example.com
    □ DNS：img → CNAME → *.cos.ap-shanghai.myqcloud.com
    □ 绑定 SSL 证书 + 强制 HTTPS
□ 自定义 CDN 加速域名 img-cdn.example.com
    □ TXT _cdnauth.example.com 归属验证通过
    □ 加速地域：中国境内；源站类型：默认源站
    □ 添加 CDN 服务授权（先）
    □ 开启回源鉴权（后）
    □ DNS：img-cdn → CNAME → img-cdn.example.com.cdn.dnsv1.com
    □ 申请 SSL 证书（私钥密码留空）→ 一键部署到 CDN
    □ 开启 HTTP 强制跳转 HTTPS；回源协议 HTTPS
□ 访问控制
    □ 防盗链白名单 example.com + 拒绝空 Referer
    □ IP 访问限频
    □ （可选）URL 时间戳鉴权
□ 高级配置
    □ 用量封顶（流量封顶 / 自然天 / 404 / 告警 80%）
□ 优化
    □ 缓存过期时间（图片 ≥30 天）
    □ COS 桶 CORS 跨域配置
□ 运维
    □ 证书 90 天到期提醒
    □ 可观测平台流量告警
    □ 验证 X-Cache: HIT
```

## 十一、密钥安全补充建议

私有读写桶意味着签名密钥就是数据大门的钥匙，几条硬规则：

1. **不要用主账号 SecretId/SecretKey**，用 CAM 子账号，策略只放开这一个桶的必要操作
2. 前端场景用 **STS 临时密钥**（有效期通常 ≤2 小时），不要把永久密钥下发到客户端
3. 密钥放**环境变量 / 密钥管理系统**，不进代码仓库
4. 定期轮换密钥；预签名 URL 的 `q-sign-time` **尽量短**（分钟级），不要签一年
5. 后端返回给前端的 URL，域名替换成 CDN 域名时做**白名单校验**，避免被利用做任意域名替换
