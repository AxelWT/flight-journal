# 读书

这里记录阅读过的书籍与读后感，以及围绕阅读主题整理的知识笔记。

## 分类

- **投资**：经典投资书籍（《聪明的投资者》《穷查理宝典》等）与基金、财报、宏观经济等投资知识笔记
- **沟通**：心理学、情绪认知、对话与心态类书籍（《道德经》《好好说话》《活出生命的意义》等）
- **艺术**：音乐、摄影等艺术领域的基础知识与教材笔记
