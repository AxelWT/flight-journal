# 《经济学的思维方式：第13版》

> 作者：保罗·海恩 / 彼得·勃特克 / 大卫·普雷契特科

---

## 2.4 值不值？效率和价值

### 技术效率 vs 经济效率

- **技术效率**：只看客观数据（如每加仑汽油能跑多少英里），不考虑人主观赋予各种取舍的价值。
- **经济效率**：从选择者的角度出发，比较各决策的**额外收益**与**额外成本**。

### 买车例子

- 第一辆车油耗 18 英里/加仑，第二辆 45 英里/加仑。从技术角度看，第二辆效率更高。
- 但若省油车定价 $30,000，SUV 定价 $24,000，许多买家会认为多花 $6,000 不值得——**额外成本 > 额外收益**。
- 买车决策不止看油耗：家庭人数、舒适度、安全性、雪地行驶能力等都影响选择。

### "值不值"因人而异

个人层面的"值不值"就是一个经济效率问题，答案取决于各人的偏好和价值观：

| 通勤方式 | 看重什么 |
|------|------|
| 开车 | 方便 |
| 坐地铁 | 避开拥堵，路上读书喝咖啡 |
| 骑自行车 | 环保 + 锻炼身体 |

每个人都在权衡额外成本与额外收益后，选择了对自己而言最有效率的方式。

### 效率之争本质是价值和权利之争

- 像"护理学学位和哲学学位哪个效率高？""砍光森林和选择性砍伐哪个效率高？"这样提问**根本没有意义**——答案完全取决于具体情况。
- 价值观决定了我们认为什么决策效率高、什么效率低。
- 社会问题上的效率之争，实质是对某种商品（或负商品）价值的争议，或对"**谁有权利做这个选择**"的争议。

> 待回答的问题并不是"究竟哪种选择效率更高"，而是"究竟谁有权利做这个选择"。

### 产权是评估的前提

- 如果游戏规则建立了**清晰、受保障的产权**，也就暗中规定了评估潜在收益和成本的流程。
- 例子：妈妈在寒冷冬日一边开窗一边开暖气——只要她有权支配所有相关资源，她的用法就是"高效"的；但若让别人的房间变冷、或账单由别人支付，产权就会受到质疑。
- 当产权**清晰、稳定、可交换**时，稀缺资源会有反映相对稀缺程度的合理价格，决策者据此追求效率。
- 批评市场价格"错误"的人，批评对象其实不是效率，而是**现存的产权体系和其他游戏规则**。
